# Draft email — Main Roads WA data enquiry

**To:** gis@mainroads.wa.gov.au
**Subject:** Open data enquiry — traffic camera imagery and incident feed for an internal logistics tool

---

Hello,

I'm enquiring about the use of Main Roads' open data in an internal tool we're
scoping at OMG Events. We run production crews and vehicles to venues around
Perth, often to fixed loading-dock times, and we're looking at building a simple
phone-based tool that helps our drivers judge conditions before they set off
between jobs.

We've found two datasets on the Main Roads open data portal that look relevant,
and I have a few questions before we go any further.

**Traffic Cameras**

1. Does the dataset include direct URLs to the current camera images, or is the
   imagery only viewable through the Travel Map?
2. How frequently are the images refreshed?
3. Is there a rate limit, or guidance on how often we should request images? We'd
   want to be a good citizen here — we'd expect to request only the handful of
   cameras relevant to a given trip, not poll the whole network.
4. Are there any conditions on redisplaying the imagery inside a tool of this
   kind?

**WebEOC Road Incidents**

5. Is this the correct feed for current incidents and closures, and how often is
   it updated?
6. Is there a preferred API endpoint for regular programmatic access?

**Licensing**

7. I understand the data is published under a Creative Commons Attribution
   licence. Could you confirm this extends to use inside a private commercial
   business tool — that is, a tool used by our own staff and subcontractors
   rather than sold or published publicly?
8. What attribution wording would you like us to display?

Happy to provide more detail on the intended use if that's helpful, and happy to
be pointed elsewhere if this isn't the right team.

Thanks for your time.

Kind regards,

Tony
OMG Events
tony@omgevents.com.au

---

## Notes before sending

- Check the signature block matches how you normally sign off (phone, position, website).
